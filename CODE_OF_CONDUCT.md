# Code of Conduct

Nocturne is a collaborative project. All participants are expected to act with
respect and professionalism.

## Standards

- Use respectful language in all channels.
- Be considerate of different levels of experience and cultural backgrounds.
- Disagree with ideas without attacking people.
- No harassment, discrimination, or intimidation.

## Reporting

If you witness behavior that violates these standards, report it to the project
maintainers through the GitHub reporting flow.
