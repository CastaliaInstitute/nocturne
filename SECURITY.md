# Security Policy

## Scope

Security concerns for embedded and platform software should be reported privately.

## How to report

If you discover a vulnerability:

1. Open a private security advisory on GitHub.
2. Include reproduction details and impact.
3. Include logs, PoC steps, and affected components if possible.

## Data handling

Nocturne is designed with local-first principles. Do not embed production secrets
in source control. Keep any test biometrics, tokens, and keys out of the repo.
