# Release and Versioning Policy

## Versioning

Nocturne follows semantic versioning (SemVer): `MAJOR.MINOR.PATCH`.

- MAJOR: breaking changes to core contracts or intent model semantics
- MINOR: new policy features, platforms, or optional modules
- PATCH: bug fixes and non-breaking changes

## Release cadence

- Patch releases: as needed for bug fixes
- Minor releases: at planned milestones
- Major releases: only with migration or compatibility notes

## Release artifacts

- Changelog entries in `CHANGELOG.md`
- Git tags for each release
- Release notes summarizing user-visible behavior, breaking changes, and migration notes
