# Nocturne Design Glossary

## Core terms

- `AcousticIntent`

  A compact vector of normalized semantic controls used by the scheduler.

- Context Domains

  - Observed
  - Computed
  - Symbolic
  - User Inputs

- Chronology

  Continuous hierarchical temporal model including year, season, solar, lunar, week, day,
  sleep phase, breath, and heartbeat layers.

- Fallback Safety Envelope

  Boundaries for brightness, novelty, event activity, density, and spectral intensity used to
  prevent abrupt or unsafe output transitions.
